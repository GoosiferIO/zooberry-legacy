A set of three new wooden fences with exhibit and decorative versions of each. Includes a matching scenery object that serves as a door that is walkable for guests and animals.

Like most user-made fences, this set uses either ingame or no descriptions to avoid needing an associated lang file. This isn't really a bug or issue, but some menu descriptions will appear blank.
