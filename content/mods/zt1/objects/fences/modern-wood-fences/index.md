A set of three new wooden fences with exhibit and decorative versions of each. Includes a matching scenery object that serves as a door that is walkable for guests and animals.

# Updates

- **Version 2.0 (April 7 2025)**: adds graphics and functionality for the deteriorated and decayed fence states, as well as shifting some parameters associated with NameIDs and HelpIDs. Version 2.0 is fully compatible with existing zoos using the previous version of the files.
- **Version 2.0.6 (April 12 2025)**: adds compatibility with the "Long Life Fence" and "Decorative Fence" menu name and tooltip strings from the LANG--ZTCDD.dll custom language file. This will require the lang file to be downloaded from ztcdd.org and placed in your Zoo Tycoon main directory, otherwise the names and tooltips in the menu will appear blank (though the fences will still work).
