A set of three new wooden fences with exhibit and decorative versions of each. Includes a matching scenery object that serves as a door that is walkable for guests and animals.

# Updates

- **2025-04-07**: Version 2.0 adds graphics and functionality for the deteriorated and decayed fence states, as well as shifting some parameters associated with NameIDs and HelpIDs. Version 2.0 is fully compatible with existing zoos using the previous version of the files.

# Known Issues

- The fences will display the names and tooltips from the concrete and plexiglass exhibit fences within the selection menu. This is an intentional compromise so that the file does not need an additional lang file associated with it.
