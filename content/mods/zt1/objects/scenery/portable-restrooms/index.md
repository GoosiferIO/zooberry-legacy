A mundane, plastic portable restroom for lower-budget zoos and parks. Functional restroom for guests, with a capacity of 2 (same as ingame Small Restrooms).

# Changelog

- **05/11/2025 v2.0**: updates the configuration to use a .ucb file instead of an .ai file and a .cfg file, in line with current standards for custom buildings. Because of this change, this will not be a direct swap for version 1.0. If you have a save file that uses version 0.0 or 1.0 of this item (prerelease up to May 11th), it is recommended that you open your zoo, delete the restrooms, then update the file, then open your zoo again and re-place the restrooms.
