## (Optional) Hack

In the downloads section below you will find an optional hack that changes the ingame locations for some of the plants above to new areas added into the game by Borsato. 

The following pieces of foliage are effected:

- Cardboard Palm (location is Central America)
- Daisy Tree (location is Galapagos)
- Madagascar Baobab (location is Madagascar)
- Speargrass (location is New Zealand)

Please note that this hack requires the following files made by Borsato to work:

- ui99.ztd (copy and paste to dlupdate)
- LANG--ZBorsato.dll (copy and paste to the main Zoo Tycoon folder)

Links to these files are available in the Dependencies section of this page.
