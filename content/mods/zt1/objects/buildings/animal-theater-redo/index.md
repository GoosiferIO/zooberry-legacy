No more bear shows! This mod replaces the original animal theatre included in base Zoo Tycoon with an edited version of the Dinosaur Digs cinema. I always found the inclusion of live animal shows kind of bizarre for a game that puts a lot of emphasis on keeping animals well looked after and various other references to the negative human impact on different species, so this mod seeks to change that. In addition, the original lang file and tooltip mentions guests visiting the cinema to watch documentaries and other shows, which doesn't match at all to the original visuals, so I think this one suits it better anyway.

As well as the building itself being changed, guests can now refill a bit of hunger and thirst by visiting the theatre, which now 'sells' snacks and drinks. The impact isn't a very strong boost, unlike the restaurants, but it's a little added bonus. Some of these snacks use name ids from official updates and expansions, but the building should still work even if you don't have these present in your copy of the game.

The one scenario that includes a pre-placed theatre, the Endangered Species Zoo, should still work and update the building accordingly.
