Aventura Folklorica is a work in progress Mexican theme pack with pueblo themes and traditional Mexican elements. Currently includes a set of 8 new foodstands in colorful adobe architectural style, and sell tamales, pozole, churros, street tacos, churros, conchas, pan de muertos, and chimichangas.

Future plans:

- More foodstands, restaurants, a fence, and some animals.

Tools used to create the sprites: 

- Blender 4.1 to create the 3D models and render them into 2D sprites
- Zoot 1.1 for ZT1 graphic conversion
- VS Code for configuration

# Notes by Jay (the coder)

> Notes: To see the messages for these, the following are needed: LANG--ZTCDD.dll dated July 14, 2026; lang018.dll that comes with CC and was also an official download; LANG--fern-Tek.dll; LANG--ZKL.dll; LANG--ZooTek.dll. 
> 
> 4 of the stands use the name "Food Stand", 3 of the stands use the name "Snack Stand", and 1 stand uses the name "Hot Beverage Stand". Whenever more than 1 building use the same name, the highlight in ZT's purchase menu will move to the first one when the purchase menu is rotated or when ZT unlocks more things or when the purchase menu is reopened. One of the stands sells a Taco. 
> 
> There is another user made stand that also sells a Taco. Both of these use different icons and slightly different characteristics. Since that stand and this stand use the same Taco messages, if that stand and this stand are in ZT at the same time, ZT will show the different taco images in the building information window for each stand, but ZT will use only 1 of the taco images and characteristics when ZT puts the taco in a guest's inventory. In general, it is unpredictable which taco ZT will choose for the guest's inventory.
> 
> (Configuration notes: removes money; can also be seen in the User Food/Drink purchase menu filter.)
