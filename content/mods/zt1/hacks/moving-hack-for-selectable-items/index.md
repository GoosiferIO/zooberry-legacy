By default, Zoo Tycoon only allows the carts and the gift stand to be moveable. This restriction makes sense from a game balancing/challenging perspective, but maybe you have played for 20 years and don’t want to lose all the pretty $$$ numbers when you bulldoze your profitable restaurant.

To move a selectable item, simply double-click on it. There is no built-in rotation adjustment mechanism, but you can rotate the map as a workaround.

Differences from Quivaz’s version: 
-This version modifies all new selectable items from Complete Collection and subsequent bonus downlods. The hack still works if you do not have all items, but you will see some unsightly blank icons in your purchase menu if you are missing something.
-The moving config actually requires an item to be selectable first to work. Quivaz’s version adds this config to a lot of non-selectable items (poos, rocks, sceneries, etc.), requiring users to edit the files further if they want the config modification to be of any use. This version, instead, only modifies existing selectable items. The restricted selection also allows it to not conflict with more item hacks. 
-One selectable item, the tank filter, is not configured because it is prone to crashing the game in my tests.
