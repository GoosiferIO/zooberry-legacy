Contains some edits to "classic" Dinosaur Digs files.

## Contains

- Already release Velociraptor\Deinonychus patch.
- Changed Caudipteryx Era from "Jurassic" to "Cretaceous"
- Make "Dinosaur Digs rocks" visible also from the Zoo Tycoon menu
- Changed era for this plants:
    - Sigillaria -> Carboniferous
    - Lepidodendron -> Carboniferous
    - Grass Tree -> Cretaceous (now is visible also from the DD menu)
    - Glossopteris -> Permian
    - Wallachia Coniferous Tree -> Permian
    - Club Moss Shrub -> Silurian
