A small mod that edits the palette and various related graphics for the Bengal tiger, turning it orange to better match the real animal.

All animal graphics have had their palette changed to an orange rather than the usual yellow. The animal adoption icons, list icons and plaque have all been updated to match the current changes.

Should be compatible with other hacks or mods that change the Tiger .ai file, as these changes are purely graphical. While this can be used in base Zoo Tycoon or an install without Marine Mania, the icon will still remain as the hybrid tropical/aquatic icon which was  introduced in said expansion.
